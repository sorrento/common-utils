# 🎨 Módulo `icons` (Iconos SVG)

Colección de iconos SVG puros en React y logos parametrizables sin dependencias externas.

---

## 🎨 Uso de Iconos

```tsx
import { Icons, LogoSvg } from '../../common-utils';

// Icono simple
<div>{Icons.search}</div>
<div>{Icons.bell}</div>
<div>{Icons.plus}</div>

// Logo SVG configurable
<LogoSvg size={48} primaryColor="#1C2434" secondaryColor="#5B7FBE" />
```
